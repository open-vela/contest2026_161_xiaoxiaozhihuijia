# PR and CI Workflow Test

This document verifies the standard contribution workflow for the openvela AI contest.

Workflow:

1. Create a development branch from `dev-ai-contest-2026`.
2. Commit changes with a Signed-off-by line.
3. Push the development branch to the participant fork.
4. Open a pull request against the upstream `dev-ai-contest-2026` branch.
5. Wait for all required CI checks to pass.
6. Review and merge the pull request according to the contest rules.
