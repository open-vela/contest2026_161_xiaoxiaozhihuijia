# 脚本用途与入口

所有参数的源码提取清单见脚本参数清单.json。下表区分可复用入口与历史工具；本轮均未执行硬件操作或编译。

|脚本|用途／输入|参数与输出|环境及版本边界|
|---|---|---|---|
|BteIntegration/bridge.py|串口BTE1解析、持久去重、TCP转发|--port、--baud、--tcp-port、--duration；可选--start-app/--observed-nsh-evidence；输出serial.bin、bridge.jsonl、summary.json|Windows QPC、Python、pyserial3.5；只收BTE1，非39B|
|run_bridge.ps1|桥接启动封装|-Port、-StartApp；同bridge输出|PowerShell，需PATH中的python|
|run_bridge.cmd|COM7桥接启动封装|无参数；固定COM7|Windows cmd；其他端口用PS或Python入口|
|bte_protocol.py|帧格式、CRC、READY和分片解析|作为模块导入，无独立命令入口|Python标准库，不连接硬件|
|audit.py|按session/event_id对账|bridge.jsonl --unity 一个或多个Unity日志 --output 新文件；拒绝覆盖|离线；区分接收、处理和实际评分|
|test_protocol.py|解析/去重软件测试|python -B -m unittest -v test_protocol|无实机证明；交叉参考仍指向原机绝对路径，其他机器会skip该项；参考解析器另存references/|
|test_unity_transport.py|模拟TCP集成测试|固定simulation/9878，输出独立模拟证据|需编辑器显式模拟模式；会连接端口，本轮未运行|
|ProtocolTests/Program.cs|生产C#解析器独立测试|dotnet restore/run，输入BTE1样例|net10.0；需.NET SDK10；测试非固件编译|
|references/parse_bte1.py|冻结参考解析器|按源码入口读取串口文本，不是新版桥接替代品|历史算法归档参考，不更新算法|
|tools/capture_legacy/serial_imu_capture.py|旧@IMU1/视频采集|--serial-port --baud --camera-index --duration-s --require-six-axis --output-dir；视频/CSV/元数据|旧采集固件；会在NSH启动应用；不能直接用于v28 BTE1|
|tools/capture_legacy/capture_front_camera_ble_accel.py|旧BLE/视频采集|--address --output-dir --meter --bpm等|bleak、OpenCV，可选pyserial；旧协议，仅冻结保留|
|ble_simulator.py|旧39B模拟输入|--tap等参数见README_legacy_39B|不能发往新版真实模式端口|

record_checks.py含原机Skill校验器绝对路径，finalize_evidence.py固化历史会话和bootfix标识，均移到review_only，不作为通用交付入口。
板端原有构建入口为CMake/Ninja及固定配置，见构建与使用说明；不提供/运行bootfix脚本，也不宣称已编制并验收一个新的自动构建脚本。

板端应用 tools/ 另保留原位采集脚本与 serial_beat_link_test.py；它们属于历史协议测试入口，不替代BteIntegration。各自参数和哈希已收入脚本参数清单；未在本轮运行。
