# 通用复现步骤

## 运行现有交付固件

适用对象：SF32LB525/N16R8 黄山派、无加密 NOR、与本项目一致的固定启动布局，以及 Windows 团结编辑器。通用指路径和串口参数可替换，不表示适用于所有开发板。

1. 核对 artifacts/v28_bootfix/nuttx.bin 的 SHA-256 与首页一致。用 `python tools/fixed_boot/check_app.py artifacts/v28_bootfix/nuttx.bin` 检查应用向量与分区范围。该检查不替代核对板上引导。
2. 若目标板已有本项目固定引导，应用地址为 0x12010000，应用区截止 0x129A0000；原校准区域 0x1200E000–0x1200FFFF 不覆盖。经用户确认烧录环境后，可使用匹配版本 sftool：`sftool -c SF32LB52 -p <实际串口名> -b 1000000 --before default_reset --after soft_reset write_flash artifacts/v28_bootfix/nuttx.bin@0x12010000`。本次整理没有执行烧录。
3. 未安装兼容固定引导的板不能直接照抄应用更新命令。首次安装先完整备份该板 Flash 并验证备份，再按布局分别写入 ftab_fixed.bin 到 0x12000000、fixed_boot.bin 到 0x12008000 和应用到 0x12010000，不写校准区、不全片擦除；此流程只适用上述无加密硬件。引导源码在 tools/fixed_boot，可用 build_fixed_boot.py 构建；交付引导来自既有安装验证，其他目标板须独立验收。
4. 电脑安装团结引擎 1.10.0／2022.3.62t12、Python 3。打开 desktop，等待资源导入，打开 Assets/Scenes/scene9.scene，使用 RhythmGame / v28 / Run real board input。scene8 保留索引但已清空删除曲目，scene1/2 已知跳转问题不作为复现入口。
5. 进入 desktop/BteIntegration，关闭其他串口读取者，运行 `python -X utf8 bridge.py --port <实际串口名>`。仅在确认 NSH 且应用未启动时附加 --start-app，它发送一次 `openvela_ble_probe --ui-paused --diag-off -c`。不要重复启动或自动复位。
6. 核对 READY 中 build_id=rank1_v28_bootfix_20260917。音乐运行时挥拍，按 session/event_id 核对 serial.bin、bridge.jsonl 和 unity_*.jsonl。结束时 Ctrl+C 关闭桥接、等待 summary.json，再停止编辑器 Play。使用 audit.py 生成新会话对账，不重放历史事件冒充现场输入。

## 从源码准备工作区

下列命令采用用户自己的 Linux 工作目录。PR 合入前应选择本次 PR 分支的 manifest；合入后使用比赛目标分支：

```sh
repo init -u https://github.com/open-vela/contest2026_161_xiaoxiaozhihuijia -b dev-ai-contest-2026 -m contest2026_161_xiaoxiaozhihuijia.xml
repo sync -c -j8
```

manifest 固定16个相关公共仓基线，并映射应用、bootfix配置。依次按 patches 中仓库名应用对应补丁，并把 dependencies/source_delta 下的新增／修改文件按相对路径覆盖到独立工作区；不要对同一修改重复应用补丁。团队应用使用 app/openvela_ble_probe。应先保存已有工作区修改，推荐全新工作区。公共依赖 PR 尚未完成。

准备 ARM GNU 工具链、CMake、Ninja 与 Kconfig 工具。历史版本记录为 ARM GCC 11.4、CMake 3.22.1、Ninja 1.10.1。令 WORKSPACE 为工作区绝对路径，TEAM 为工作区中的比赛仓库路径；CMake 使用原有方法：

```sh
cmake -S "$WORKSPACE/nuttx" -B "$WORKSPACE/out/v28_bootfix" -G Ninja   -DBOARD_CONFIG="$TEAM/board/v28_bootfix/board_config_i2c3"   -DNUTTX_APPS_DIR="$WORKSPACE/apps"   '-DEXTRA_FLAGS=-DBLE_PROBE_SERIAL_ONLY=0 -DBLE_PROBE_ONBOARD_BEAT=1 -DBLE_PROBE_ONBOARD_BEAT_DIAG=1 -DBLE_PROBE_JOINT_UI_BLE=1 -DBLE_PROBE_CAPTURE_ACK_ONLY=0 -DSF32LB52_ACL_OBSERVER=0 -DHB_EVAL_STRIDE=2'
cmake --build "$WORKSPACE/out/v28_bootfix" -j8
python3 "$TEAM/tools/fixed_boot/check_app.py" "$WORKSPACE/out/v28_bootfix/nuttx.bin"
```

这是基于归档参数整理的可迁移构建说明，本轮未执行全新目录配置、编译或烧录，不能标记为干净环境复现已通过。新编译产物须重新记录配置、SHA-256、READY 与实机结果；不得用现有归档哈希替代新构建校验。

## 证据范围

最终运行固件为 bootfix，实机证据见 evidence/v28_bootfix。七条桌面反馈来自删曲前 scene8，当前 scene9 不继承该场景验收。original 保留其 app_reference、source_override 与 patches/original，仅作原布局对照，不能与 bootfix配置、补丁混用。采集工具保留手工同步，不与 BTE1 桥接同时占用串口。
